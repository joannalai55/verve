# Practice and memory

## Build "my words"

Move each item through four abilities:

1. recognize it in context;
2. retrieve its meaning without cues;
3. produce it in a new sentence;
4. choose it appropriately under social or time pressure.

Do not mark an item owned merely because the user recognizes it. Ownership requires repeated production across contexts.

## Capture useful items

Prefer high-frequency collocations, complete conversational moves, phrases with a clear social function, productive sentence frames, and short delivery chunks with memorable rhythm.

For each item, preserve exact text, plain-English meaning, original encounter, register and tone, a natural example, scenario tags, and a common misuse or nearby contrast when valuable.

## Run review games

Retrieve due items with the library script. Show one prompt at a time and hide the answer until the user commits.

Rotate among:

- **Situation to phrase**: give a scenario; ask for the saved expression.
- **Finish the line**: remove the key chunk.
- **Tone switch**: rewrite the same intent for work, friendly chat, or flirting.
- **Constraint**: require the item in a reply under 12 words.
- **Spot the mismatch**: choose which situation makes the phrase awkward.
- **Comeback**: respond naturally using the target chunk.
- **Story stitch**: use three due items in one coherent anecdote.

Score recall by production quality, not the user's confidence report. Explain the score briefly and record it.

## Train chunks

Use this sequence:

1. establish meaning and subtext;
2. mark thought groups and stressed words;
3. identify the rhetorical or conversational move;
4. have the user mimic the line;
5. replace the content while preserving the structure;
6. invent a realistic situation where it fits;
7. improvise a nearby line without the template.

When audio is available, focus on one audible feature per repetition. When it is not, use stress marking, pauses, and recording instructions without pretending to hear the result.

## Practise speaking

Select one mode:

- **Daily talk**: short turns, follow-up questions, repair strategies, natural reactions.
- **Casual chat**: speed, fragments, playful specificity, topic changes.
- **Presentation**: signposts, breath groups, emphasis, transitions, endings.
- **Pitch**: problem tension, contrast, evidence, audience stakes, call to action.

Increase pressure gradually: unlimited preparation, keywords only, five-second preparation, interruption or follow-up, tone switch, then a fresh scenario using the same move.

Give delayed feedback after a role-play unless interruption is requested. Limit each round to one language goal and one delivery goal.

## Design a session

For a 5-minute session:

1. one due-item recall;
2. one real-life rewrite or response;
3. one spoken or typed improvisation;
4. one item saved or reviewed.

For 10–20 minutes, add a role-play and a second attempt under tighter constraints. End with one observable win and one next target, not a generic motivational speech.
